# Phase D.4 Occupancy RTL Walkthrough

The Facility Workspace occupancy section uses Arabic labels and RTL ordering.

Desktop:
- Command strip shows status, source, and occupancy percentage.
- Metrics show capacity, count, vacancy, and over-capacity.
- Unit load rows show capacity bars and status text.

Tablet/mobile:
- Rows stack without horizontal scrolling.
- Unit context opens inside the existing Workspace panel/focus flow.
- Color is paired with text labels, not used alone.
