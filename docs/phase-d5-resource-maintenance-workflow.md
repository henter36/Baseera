# Phase D.5 Resource Maintenance Workflow

`MaintenanceWorkOrder` supports preventive, corrective, inspection, calibration, emergency, warranty, recall, and other work.

Statuses: Open, Assigned, InProgress, AwaitingParts, AwaitingVendor, Completed, Cancelled, Rejected.

Phase D.5 creates and displays maintenance work orders. Advanced completion commands, acceptance checks, vendor workflows, and cost handling remain future work. Maintenance does not change ownership and does not silently return a safety-critical resource to service.
