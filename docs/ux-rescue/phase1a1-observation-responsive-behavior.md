# Phase 1A.1 — Responsive Behavior

## Desktop

| الشرط | السلوك |
| --- | --- |
| لا يوجد `noteId` | تظهر القائمة وحالة اختيار داخل Detail Pane |
| يوجد `noteId` | القائمة والتفاصيل مرئيتان معًا |
| اختيار ملاحظة | يحدث `noteId` في URL ويفتح التفاصيل داخل الصفحة |
| إغلاق التفاصيل | يزيل `noteId` ويحافظ على الفلاتر |
| previous/next | يغير `noteId` ضمن النتائج المحملة |

القائمة والتفاصيل تستخدمان تمريرًا مستقلًا داخل مساحة العمل عند الحاجة.

## Tablet

القائمة تبقى جزءًا من الصفحة لكنها تضيق. زر طي القائمة يستخدم `view=detail`/state محلي قائم ولا يحول التفاصيل إلى drawer.

## Mobile

| الحالة | السلوك |
| --- | --- |
| بدون `noteId` | القائمة فقط |
| مع `noteId` | Detail Focus Mode داخل الصفحة |
| زر الرجوع | يزيل `noteId` فقط |
| Browser back | يعيد حالة URL السابقة |
| Refresh | يعيد نفس الملاحظة عند وجود `noteId` |

لا يوجد Bottom Sheet أو Full-screen Dialog.
