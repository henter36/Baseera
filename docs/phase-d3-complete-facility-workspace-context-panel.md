# Phase D.3 Context Panel

The Context Panel supports:

- `note`: full note workspace detail and safe inline note actions already supported by APIs.
- `corrective-action`: corrective action detail and status history preview.
- `escalation`: safe escalation summary because occurrence-specific preview APIs are not yet available.
- `form-assignment`: form compliance preview with full-page fallback for fill/review.
- `facility-unit`: unit-level structure and operational counts.
- `incident`, `risk`, `vehicle`, `weapon`, `communication-device`, `equipment`, `project`, `emergency-plan`, `decision`: safe gap preview until domain models and APIs exist.
- `activity`: bounded event preview.

The panel keeps URL state and does not replace server-side authorization. Full-page links remain secondary.
