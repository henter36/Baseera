# Phase D.3 Visual Comparison

Phase D.2 already moved the Facility Workspace from traditional dashboard cards to a command-center layout. Phase D.3 keeps that visual system and expands it with operational sections.

Changes from D.2:

- The navigation now covers all prison operation domains.
- The overview includes domain coverage rather than only note/action/form cards.
- Occupancy and resources use rails and operational rows.
- Data quality is a first-class section.
- Context Panel can explain missing domain sources safely.

Screenshots captured from the running local API and Vite app are stored under `docs/screenshots/phase-d3/`:

- Desktop: overview, priorities, resources, risks, projects, plans, decisions, Context Panel, partial state, and empty state.
- Tablet: overview.
- Mobile: overview, resources section, and detail panel flow.
