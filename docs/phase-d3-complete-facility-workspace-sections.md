# Phase D.3 Facility Workspace Sections

1. `overview`: overall scene, operational pulse, domain coverage.
2. `urgent`: intervention queue from supported real sources.
3. `operations`: notes/actions/escalations and supported recent operational events.
4. `occupancy`: facility units and explicit occupancy data gap.
5. `resources`: structural asset-location availability and resource inventory gap.
6. `risks`: explicit risk engine gap.
7. `projects`: explicit project/initiative gap.
8. `compliance`: form compliance using the existing service.
9. `plans`: explicit operational/emergency plan gap.
10. `decisions`: explicit decision/directive gap.
11. `timeline`: bounded recent activity from supported sources.
12. `data-quality`: coverage and impact of missing data domains.

Sections are selected with `?section={key}` and do not reload the workspace shell.
