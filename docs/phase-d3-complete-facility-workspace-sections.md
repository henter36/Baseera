# Phase D.3 Facility Workspace Sections

Current Facility Workspace internal navigation (D.3 base + later domain slices):

1. `overview`: overall scene, operational pulse, domain coverage.
2. `urgent`: intervention queue from supported real sources.
3. `operations`: notes/actions/escalations and supported recent operational events.
4. `occupancy`: facility occupancy and inmate movement (D.4).
5. `resources`: core asset readiness (D.5).
6. `workforce`: القوى البشرية والتغطية — staffing coverage and duty readiness (D.5.1).
7. `risks`: explicit risk engine gap.
8. `projects`: explicit project/initiative gap.
9. `compliance`: form compliance using the existing service.
10. `plans`: explicit operational/emergency plan gap.
11. `decisions`: explicit decision/directive gap.
12. `timeline`: bounded recent activity from supported sources.
13. `data-quality`: coverage and impact of missing data domains.

Sections are selected with `?section={key}` and do not reload the workspace shell.
