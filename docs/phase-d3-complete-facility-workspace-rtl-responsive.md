# Phase D.3 RTL and Responsive Walkthrough

The Facility Workspace remains Arabic RTL.

Desktop:

- Sticky command header.
- Main section content with Intervention Queue on the side.
- Context Panel opens on the inline end side.

Tablet:

- Command grid collapses to a single column when width is constrained.
- Section navigation remains horizontally scrollable.

Mobile:

- Command header stacks.
- Context Panel becomes full-screen detail mode.
- Lists use touch-sized buttons and avoid horizontal scrolling.

Keyboard:

- Priority rows and unit/data-quality rows are buttons.
- Context Panel receives focus on open and Escape closes it.
